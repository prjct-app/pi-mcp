# Issue tracker and pull requests

Use GitHub for `prjct-app/pi-mcp`. Contributor-facing text is English.

- Read an issue with `gh issue view <number> --repo prjct-app/pi-mcp`.
- Read a pull request with `gh pr view <number> --repo prjct-app/pi-mcp`.
- Feature PRs target `develop` and use `.github/pull_request_template.md`.
- The initial implementation originates in the user conversation, recorded in
  `docs/spec-mcp-client.md`; no originating issue number is claimed.
- Pushing, opening/merging PRs, changing visibility, and publishing require explicit
  user authorization. Local testing is not publication authorization.
